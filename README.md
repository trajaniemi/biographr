# biographr

<!-- badges: start -->

<!-- badges: end -->

Graphing and Statistics for Biology Students

Creates graphs and does statistical analysis for biological data. The
goal of biographr is to act as a user-friendly app for graphing and
statistical data analysis appropriate for undergraduate biology majors.

## Installation

You can install biographr from [GitHub](https://github.com/) with:

``` r
# install.packages("devtools")
devtools::install_github("trajaniemi/biographr")
```

## Usage

To open biographer use

``` r
biographr::run_app()
```
